Privacy Policy

Last updated: 22 November 2026

Clip Uploader is a personal tool. Its only user is the owner of the connected YouTube channel.

What it accesses

With the owner's permission (Google OAuth), Clip Uploader uses the YouTube Data API to upload videos to the owner's channel and to read the channel's name. It does not access any other Google or YouTube data, and it does not access data of any other YouTube user.

How data is stored

The OAuth token is stored only on the owner's computer and as an encrypted secret in the owner's private GitHub repository. Video files waiting to be posted are stored in that private repository and deleted after they are posted.

Sharing

No data is sold, shared with third parties, or used for advertising. Clip Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

Clip Uploader uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access invalidates the stored token; the owner can also delete the token files and repository secret at any time.
